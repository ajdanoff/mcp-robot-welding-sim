# Математические основы кинематики промышленных манипуляторов

Этот документ описывает математический аппарат, реализованный в модуле `src/mcp_robot_welding/kinematics.py`: от базовых определений кинематической цепи до дифференциальной кинематики и численного решения обратной задачи методом Левенберга — Марквардта.

---

## 1. Базовые определения

- **Звено (Link):** твёрдое тело манипулятора, соединяющее два соседних сочленения. Нумерация начинается с неподвижного основания `0` и заканчивается фланцем инструмента `n`.
- **Сочленение / Сустав (Joint):** кинематическая пара с одной степенью свободы (DoF), соединяющая два смежных звена.
  - *Вращательный сустав (Revolute, R):* обобщённая координата — угол поворота $q_i = \theta_i \in R$.
  - *Поступательный сустав (Prismatic, P):* обобщённая координата — линейное смещение $q_i = d_i \in R$.
- **Пространство обобщённых координат (Joint Space, Q):** вектор конфигураций всех `n` суставов робота:

```text
q = [q1, q2, ..., qn]^T ∈ R^n
```

- **Рабочее пространство (Task / Operational Space, SE(3)):** пространство положений и ориентаций рабочего инструмента (**TCP — Tool Center Point**) в декартовой системе координат базы робота. Поза инструмента задаётся матрицей однородного преобразования размерности `4 x 4`:

```text
T = | R  p |
    | 0  1 |

T ∈ SE(3)
R ∈ SO(3)
p ∈ R^3
```

где `R` — ортогональная матрица поворота (`det(R) = +1`, `R^T R = I`), а `p = [x, y, z]^T` — вектор координат кончика сварочной горелки.

---

## 2. Прямая задача кинематики (Forward Kinematics, FK)

**Определение:** по заданному вектору углов или смещений в суставах `q` вычислить положение и ориентацию инструмента `T_tcp(q)` в базовой системе координат:

```text
f: Q -> SE(3)

T_tcp(q) = T_0^1(q1) * T_1^2(q2) * ... * T_(n-1)^n(qn)
```

### Параметризация Денавита — Хартенберга (DH)

Переход между соседними системами координат `i - 1` и `i` описывается четырьмя параметрами `(a_i, alpha_i, d_i, theta_i)` и раскладывается на четыре элементарных преобразования:

```text
T_(i-1)^i(theta_i) =
    Rot_z(theta_i) *
    Trans_z(d_i) *
    Trans_x(a_i) *
    Rot_x(alpha_i)
```

Матрица однородного преобразования:

```text
T_(i-1)^i =
| cos(theta_i)  -sin(theta_i) * cos(alpha_i)   sin(theta_i) * sin(alpha_i)   a_i * cos(theta_i) |
| sin(theta_i)   cos(theta_i) * cos(alpha_i)  -cos(theta_i) * sin(alpha_i)   a_i * sin(theta_i) |
| 0              sin(alpha_i)                  cos(alpha_i)                  d_i                |
| 0              0                             0                             1                  |
```

### Свойства прямой задачи

- Решается аналитически и однозначно за `O(n)` матричных умножений.
- Помимо позы кончика горелки `T_tcp`, цепочка промежуточных матриц `T_0^k(q)` даёт координаты всех суставов в пространстве.
- Эти промежуточные системы используются в `scene.py` для проверки столкновений каждого звена с препятствиями.

## 3. Обратная задача кинематики (Inverse Kinematics, IK)

**Определение:** по заданной целевой позе инструмента `T_target = (R_target, p_target) ∈ SE(3)` найти вектор обобщённых координат `q*`, при котором инструмент попадает в целевую точку с требуемой ориентацией:

```text
f(q*) = T_target
```

### Почему обратная задача сложнее прямой

1. **Нелинейность:** уравнения содержат произведения тригонометрических функций `sin(q_i)` и `cos(q_i)`, поэтому прямого матричного обращения `q = A^-1 x` в общем виде не существует.

2. **Множественность решений:** одной и той же точке в пространстве могут соответствовать разные конфигурации звеньев, например:
   - «локоть вверх» и «локоть вниз»;
   - «плечо вперёд» и «плечо назад»;
   - «переворот запястья».

3. **Недостижимость и сингулярности:** если цель находится за пределами рабочей зоны `||p_target|| > R_max`, или две оси суставов выстраиваются в одну линию, матрица Якоби теряет полный ранг.

## 4. Дифференциальная кинематика и геометрический якобиан

Для численного решения IK нелинейная задача линеаризуется в окрестности текущей конфигурации `q` с помощью матрицы Якоби `J(q) ∈ R^(6 x n)`. Она связывает скорости в суставах `q_dot` с линейной `v` и угловой `omega` скоростями инструмента:

```text
| v     |   | J_v |
| omega | = | J_w | * q_dot

Delta X ≈ J(q) * Delta q
```

### Аналитическое построение столбцов якобиана

Для каждого вращательного сустава `i` столбец `J_i ∈ R^6` вычисляется напрямую из матриц `T_0^i`, полученных при прямом проходе.

Линейная часть:

```text
J_v_i = z_i x (p_tcp - p_i)
```

Угловая часть:

```text
J_omega_i = z_i
```

где:

- `z_i` — единичный вектор оси вращения `i`-го сустава;
- `p_i` — начало координат `i`-го сустава;
- `p_tcp` — координаты кончика инструмента;
- все величины выражены в базовой системе координат.

## 5. Вектор ошибки на SE(3) и метод Левенберга — Марквардта

На каждой итерации вычисляется шестимерный вектор невязки:

```text
e = [e_pos^T, e_rot^T]^T ∈ R^6
```

### Ошибка позиции

Ошибка позиции определяется как разность между целевой и текущей позициями TCP:

```text
e_pos = p_target - p_current(q)
```

### Ошибка ориентации

Ошибка ориентации вычисляется через логарифмическое отображение `SO(3) -> so(3)`.

Матрица относительного поворота:

```text
R_err = R_target * R_current^T
```

Она переводится в вектор конечного поворота: ось `u_hat`, умноженная на угол `phi`.

```text
phi = acos((tr(R_err) - 1) / 2)

e_rot = (phi / (2 * sin(phi))) *
        [
            R_err[2,1] - R_err[1,2],
            R_err[0,2] - R_err[2,0],
            R_err[1,0] - R_err[0,1]
        ]
```

### Регуляризация шага: Damped Least Squares

Прямое обращение:

```text
Delta q = J^-1 * e
```

расходится вблизи сингулярностей, где `det(J) -> 0`.

Метод Левенберга — Марквардта добавляет коэффициент демпфирования `lambda > 0`:

```text
Delta q = (J^T * J + lambda * I)^-1 * J^T * e
```

- При `lambda -> 0` алгоритм ведёт себя как быстрый метод Ньютона — Гаусса.
- Вблизи сингулярностей демпфирование `lambda * I` гарантирует обратимость матрицы и ограничивает скачки скоростей суставов.

### Мультистарт и выбор плавной траектории

Решатель запускается из нескольких начальных конфигураций (`seeds`) и среди всех сошедшихся решений выбирает то, которое минимизирует максимальный скачок углов относительно предыдущей точки траектории:

```text
min max_i |q_i - q_prev_i|
```

Это позволяет предпочесть более плавное и исполняемое решение при наличии нескольких допустимых конфигураций IK.
